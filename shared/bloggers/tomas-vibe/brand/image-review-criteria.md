# Критерии ревью промпта и картинки — tomas-vibe

Для Lens: `prompt_review` / `image_review`. Опирайся на `visual-tg.md` и `visual-vibe.md`.

## Prompt review

1. **Стиль:** Fallout Vault Boy, matrix green, тёмный фон, neon green tints, digital retrofuturism, cyberpunk meets 1950s — не палитра food-канала (sepia-amber).
2. **Сюжет:** Vault Boy в сцене по **`post_summary.txt`** (вайб-кодинг / агенты / инструменты).
3. **Формат:** квадрат 1:1, `no text` в позитивном промпте, явный `Negative:`.
4. **Язык:** английский, последовательный негатив без противоречий.

**REJECT**, если промпт уходит в food-палитру, stock UI без Vault Boy, или смешивает каналы.

## Image review

1. Доминируют **тёмный фон** и **зелёный неон** из гайда.
2. Vault Boy читается в миниатюре Telegram.
3. Нет лишнего текста и водяных знаков.
4. Качество рендера, соответствие промпту.

**REJECT** при несоответствии бренду или низком качестве.
