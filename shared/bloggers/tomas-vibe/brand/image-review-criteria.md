# Критерии ревью промпта и картинки — tomas-vibe

Для Lens: `prompt_review` / `image_review`. Опирайся на `visual-tg.md` и `visual-vibe.md`.

## Prompt review

1. **Эстетика:** тёмный минимализм, tech / product UI vibe, без «корпоративного стока» и без лишних людей в кадре, если бренд этого не требует.
2. **Акцент:** один читаемый акцентный цвет/свет, сетка и структура как в гайде.
3. **Формат:** соответствие платформе (tg превью — квадрат 1:1, если так задано в visual-tg).
4. **Язык промпта:** английский, последовательный негативный промпт без противоречий.

**REJECT**, если промпт уводит в сток, светлый фон без обоснования или стиль не совпадает с vibe-кодинг / AI-агенты.

## Image review

1. Визуал совпадает с dark minimal tech из гайда.
2. Нет клишированного stock-UI «как у всех», если задана уникальность бренда.
3. Чистота композиции, читаемость в миниатюре Telegram.
4. Качество рендера, отсутствие артефактов и лишнего текста.

**REJECT** при несоответствии бренду или низком качестве.
