# Критерии ревью промпта и картинки — nasik

Для Lens: `prompt_review` / `image_review`. Опирайся на `visual-tt.md` (TikTok 9:16).

## Prompt review

1. **Настроение:** живой, контрастный, вирусный; энергия и движение.
2. **Палитра:** чёрный #0a0a0a или карамельный #92400e, акцент #f59e0b; без бежевой пастели как основного фона (см. негатив гайда).
3. **Кадр:** мобильная съёмка, динамика, пар/лёд/всплески где уместно; **9:16**.
4. **Негатив:** исключить статичные медленные кадры и студийную «пластиковую» постановку — по visual-tt.

**REJECT**, если промпт статичный, «инстаграмно-мягкий» или не даёт tiktok-энергии.

## Image review

1. Кадр ощущается динамичным и контрастным, не пастельной заливкой.
2. Вертикаль 9:16, читаемость в ленте TikTok.
3. Качество; нет лишнего текста на изображении без задачи.
4. Соответствие палитре и настроению бренда.

**REJECT** при визуальном несоответствии гайду или слабом качестве рендера.
