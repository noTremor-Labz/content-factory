# Cross-Session Guide: Content Factory

> For any agent joining this project mid-work.

## Start Here

1. Read `/Users/tomasrabi/DEV/shared/identity.md`.
2. Read `.memory/context.md`.
3. Read the latest handoff from `.memory/sessions/`.
4. For business/product/strategy tasks, read `.business/INDEX.md`, then only the relevant `.business/*` files.
5. Read `AGENTS.md` or `CLAUDE.md`.

## How to Continue

- Check `git status`.
- Check the latest handoff for the recommended next step.
- Do not select or scaffold a technical stack unless the current task requires that decision.
- For non-trivial work, use `shared/skills/bulletproof/SKILL.md`.

## How to Handoff

When finishing work:

1. Self-audit against the user's request and any acceptance criteria.
2. Write a handoff file to `.memory/sessions/YYYY-MM-DD-{agent}-{phase}.md`.
3. Generate a snapshot in `.memory/snapshots/`.
4. Update `.memory/context.md`.
